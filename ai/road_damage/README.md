# Road Damage

YOLO11n road-damage detection pipeline for potholes and pavement cracks.

## Classes

- D00 — Longitudinal Crack
- D10 — Transverse Crack
- D20 — Alligator Crack
- D40 — Pothole

The current trained weights are kept outside Git due to binary size. Training checkpoints are persisted separately and can be copied locally for inference.
